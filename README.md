# Tera Twin — مشروع موحّد (v1.4)

دمج لملفات React/Three.js الخاصة بمستكشف الكواكب مع واجهة **Mission Lab** وصفحة الهبوط في تطبيق واحد متناسق باسم **Tera Twin**.

## ماذا تم دمجه؟
- **Twin Explorer**: كرات ثلاثية الأبعاد للأرض/المريخ/القمر + خريطة مسطحة، شبكة إحداثيات، علامات، مقارنة تضاريس، وجداول حقائق.
- **Candidate Sites**: أماكن مرشحة/افتراضية غير مكتشفة، مع مقارنة في الاتجاهات الستة (الأرض↔المريخ، الأرض↔القمر، المريخ↔القمر) حسب الحرارة، الجاذبية، احتمال الماء، إمكانية المعيشة، خطر النيازك، خطر الشمس، والغبار.
- **Mission Lab**: اختيار مواقع ميدانية، أوزان معايير، تحليل فوري، رادار قدرات، كرة أرضية لتحديد المواقع، صور أرشيفية، لوجستيات، تنبيهات هندسية، جاذبية، وتقرير قابل للتنزيل.
- **واجهة موحّدة**: Header/Hero/Worlds/Missions/Footer، لغة عربية/إنجليزية مشتركة مع RTL، تصميم متجاوب، وهوية بصرية أقوى.
- **وضعان للعرض**: زر تبديل بارز في الشريط العلوي بين Dark / Light، مع حفظ الاختيار في المتصفح والرابط (`?theme=light|dark`).
- **هوية بصرية أقوى**: شعار مداري، لوحة مفاهيم في الـ Hero، وبطاقات تعريفية سريعة للأقسام الثلاثة.
- **حالة مشتركة في الرابط**: لغة الصفحة وإعدادات Mission Lab تُحفظ في query parameters.

## التشغيل
```bash
npm install
npm run dev        # خادم تطوير على المنفذ 5173
npm run build      # ينتج ملفاً واحداً self-contained في dist/index.html
npm run preview    # معاينة نسخة الإنتاج على المنفذ 4173
npm run typecheck  # فحص TypeScript
npm run test:e2e   # اختبار Playwright (يتطلب تثبيت متصفح Playwright)
```

> نسخة الإنتاج مبنية بـ `vite-plugin-singlefile`: كل JS/CSS/الصور مضمّنة داخل `dist/index.html`، لذا يمكن فتحه مباشرة أو مشاركته كملف واحد.

## بنية مختصرة
```
src/
  app.tsx       # الواجهة كاملة: Header/Hero/Explorer/Candidates/Mission Lab/Worlds + الثيم واللغة
  data.tsx      # البيانات + النصوص ثنائية اللغة + منطق المقارنة + الصور
  engine.tsx    # محرك الكرة/الخريطة/العلامات + الإحداثيات
  styles.css    # كل الأنماط (متغيرات Dark/Light)
  assets/       # الخامات والصور المحلية
```

## ملاحظات الدمج
- الملفات المرفقة لم تكن تحتوي على `style.css` أو `script.js` أو `twin-finder.js/css` المشار إليها في `index-2.html`. تم استبدال الأجزاء الناقصة بمكوّنات React داخل المشروع، وأعيد استخدام محرك الكرة الحالي بدل ازدواجية التطبيقات.
- صور الخامات وصور NASA الميدانية حُمّلت محلياً داخل `src/assets` حتى لا تعتمد الواجهة على روابط خارجية وقت التشغيل.
- خرائط الـ bump للمريخ/القمر مشتقة بصرياً من خرائط الألوان لإبراز التفاصيل، وليست بيانات ارتفاع علمية.
- تم توحيد اللغة إلى EN/AR بدل وضع "both" القديم لتفادي ازدواجية النصوص في كل الأقسام.
- تم دمج ملفات الكود والأنماط لتقليل عدد ملفات المشروع (من 57 إلى 29 ملفاً دون احتساب node_modules/dist/artifacts).
- تمت إزالة الحزم غير المستخدمة (`clsx`, `tailwind-merge`).

## إخلاء مسؤولية علمي
درجات Mission Lab ومؤشرات الوصول/التكلفة هي **أداة مقارنة تخطيطية توضيحية** وليست توصية من NASA أو مسحاً معتمداً للموقع أو إرشادات سلامة تشغيلية. أماكن Candidate Sites **افتراضية/مرشحة وليست اكتشافات مؤكدة**، وقيم الحرارة/الماء/المعيشة/المخاطر تقديرية للمقارنة فقط. صور الأسطح مشتقة من بيانات NASA، لكن مواقع المعالم تقريبية للأغراض التعليمية.
